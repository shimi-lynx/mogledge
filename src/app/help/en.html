Send to AI

Ask your AI to create or improve an HTML app, explain a document, or work with a folder.

  1. Choose the target. Right-click an HTML file or folder and choose “Send to AI”.
  2. Choose your AI and add a request. For example: “Make a weekly planner that saves my input.” A blank request is also allowed.
  3. Open the draft or copy the request. Check the working directory and full draft in your AI tool, then send it there.

HTML content and saved input are not sent automatically.

Create and edit in a local folder. Use an ordinary local folder outside OneDrive sync. File and folder operations inside OneDrive sync folders may fail.

Other ways to start and what is passed
  • For the whole knowledge folder, right-click the folder selector. You can also use the AI button on a tree row, or Ctrl+Shift+A on Windows / Cmd+Shift+A on macOS for the active document.
  • ChatGPT / Codex, Claude Code and Claude Code CLI open an unsent draft. The target tool must be installed and its link handler registered.
  • A file draft includes its path and uses its parent folder as the working directory. A folder draft uses that folder as the working directory; its text contains only your request.
  • “Copy request” includes the selected path and your request. Codex CLI uses this copy: choose its working directory, start Codex, paste into its input, and check before sending. Paste the request into the AI, not into a shell.
  • If the AI app does not open, copy the request and pass it manually. Mogledge does not change your AI tool’s permissions or approval settings.

What else you can do

Switch between HTML apps quickly

Mogledge opens HTML files from your knowledge folder in tabs or in two columns. Switching, reordering or moving tabs, and opening or closing the sidebar keeps input, canvas and JavaScript state. Opening the same HTML in both columns creates separate views with independent state.

Open by name, full text or favorites

  • Quick Open: find by name or relative path; up to 20 matches.
  • Full-text search: find words inside HTML; 20 results per page, with a folder filter.
  • Favorites: keep up to 50 documents and folders for each knowledge folder, including while searching.
  • Recent: use the clock button for up to 50 recent documents. A favorite folder takes you to that location in the tree.

Save a workspace

Save up to 10 workspace sets with 30 documents each, including columns, tab order, selection and zoom. Restoring a set keeps existing views and loads new, unselected documents only when you select them. Input values are not part of a workspace set.

Assign a workspace shortcut

Assign Ctrl/Cmd+Shift+1–0 to sets in the manager; 0 is slot 10. The ten slots belong to this root and retain stable set IDs when names or order change. Unassigned keys do nothing; deleting a set clears its assignment without assigning another set. These shortcuts work within the app and give priority to HTML shortcuts, inputs, IME and dialogs.

History and zoom

Back and Forward keep up to 32 entries for each column. Reopen up to 10 recently closed documents during the current session. Each document can use 50–200% zoom without changing the size of the app controls.

Manage files and folders

Use the tree to create HTML files and folders, rename, reorder, move, send to the trash, copy paths or open with your OS. Edit HTML content with your external AI tool or editor.

Create and edit in a local folder. Use an ordinary local folder outside OneDrive sync. File and folder operations inside OneDrive sync folders may fail.

Manage saved input

HTML apps that use the storage API can restore their saved input. Exporting or importing input asks you to choose files and any required backup, then confirm replacement and stopping or reloading views. Check the contents of the plain-text JSON and store it safely.

Open a document

  1. Open the root selector or Settings → Mogledge folders. Create a new dedicated folder or register an existing folder, then choose it from the list. Setup installs the guide, template and Codex / Claude Skills without overwriting conflicting files. Child folders appear in the normal tree. Unregistering keeps the folder, HTML and saved data. If a folder moved, register its new location to reconnect its management marker.
  2. Select HTML from the tree, Quick Open or full-text search. Return to Files when you do not need search.
  3. Right-click a tree item or tab to open it in the left or right column. Drag tabs to reorder them or move them between columns.

The sidebar and tabs

The top-left icons toggle the sidebar, Files and Search. Drag the divider to resize the sidebar, or focus it and use the arrow, Home and End keys. On a narrow window the sidebar covers the document area.

Favorites appear below the creation buttons; scroll inside the frame for more entries. The workspace sets icon in the title bar opens saving and restoring sets. The rightmost help icon selects this same tab. Close a tab with its × button, a middle click or the close shortcut while the tab is focused.

Open Settings at the bottom of the sidebar and choose “Select display language” to switch between Japanese and English. English is the first-launch default. Your choice applies immediately and is kept for the next launch. The version appears at the bottom left.

Create and move files

Create and edit in a local folder. Use an ordinary local folder outside OneDrive sync. File and folder operations inside OneDrive sync folders may fail.

The creation buttons are HTML, folder and root folder. Choose destinations from the folder list and type to filter relative paths. Typed text is a filter, not an arbitrary path to write.

Find words inside HTML

  • Open “Search options” beside the query. Choose AND/OR and a folder, including its subfolders. The options and open state are kept for the next launch.
  • “Reset search conditions” restores AND and the entire knowledge folder. It keeps the query and the options’ open state.
  • The × inside the query clears only the query and results. Escape clears the query first, then returns to Files when it is empty.
  • Right-click a folder and choose “Search in this folder”. Clear the scope with × to search the entire knowledge folder.

Document IDs and saved data

Saved data follows the document UUID across dedicated folders. A valid unique ID restores automatically. If the ID is missing, invalid or duplicated, HTML remains viewable while saving is held. Use Review document ID in the app notice to add an ID, share duplicate saved data, or assign a new ID to a duplicate. These explicit actions modify the HTML. Legacy physical-identity data is not checked or automatically inherited by this UUID workflow. Existing data and backups are not deleted. Save input in each HTML app before switching folders or reloading.

Updates and saving

Saving externally updates the visible document. Hidden tabs keep their running state and show an update marker. “Reset state and reload” resets input, canvas and JavaScript state.

The storage API saves input, not the entire JavaScript or canvas state. Complete saving within the document before resetting or quitting. Check relative links with your external editor after renaming or moving HTML files.

Create, modify and trash files in ordinary local folders. A failed trash operation never falls back to permanent deletion. Restore files through your OS trash.

For OneDrive, browse items already kept on the device. Use your OS to keep online-only items locally before opening them. Windows requires WebView2; macOS requires version 12 or later.

Main shortcuts

Ctrl+W / Cmd+W works from app controls and unhandled HTML focus. Editing, IME, dialogs and HTML cancellation take priority. Holding the key closes only one tab; the last tab never closes the app.

Switch help sections

Tab to the section choices, then use the arrow keys or Space to select one. Tab again to focus the visible content and scroll with arrow keys, Page Up or Page Down.
