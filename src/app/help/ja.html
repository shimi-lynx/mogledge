機能と使い方

表示する内容

まずはここから

AIに渡す

HTMLアプリの作成・改善、文書の説明、フォルダー内の作業を外部のAIに頼めます。

  1. 対象を選ぶ。 HTMLやフォルダーを右クリックし、「AIに渡す」を選びます。
  2. 連携先と依頼文を決める。 例：「入力を保存できる週間プランナーを作って」。依頼文は空でも開けます。
  3. 下書きを開くか、依頼文をコピーする。 相手のAIで作業フォルダーと全文を確認し、そこで送信します。

HTML本文や保存入力を自動で送信しません。

作成・編集は同期外のローカルフォルダーで。 OneDrive同期外の通常のローカルフォルダーを使ってください。OneDrive同期フォルダー内のファイル・フォルダー操作は失敗する場合があります。

ほかの入口・渡す内容
  • knowledge全体ならフォルダー選択欄を右クリックします。ツリー行のAIボタン、表示中の文書でWindowsのCtrl+Shift+A／macOSのCmd+Shift+Aも使えます。
  • ChatGPT / Codex、Claude Code、Claude Code CLIでは未送信の下書きを開きます。連携先の導入とリンク登録は別途必要です。
  • ファイルはパスを本文に含め、親フォルダーを作業フォルダーにします。フォルダーはその場所を作業フォルダーにし、本文には自分の依頼文だけを渡します。
  • 「依頼文をコピー」は対象パスと依頼文を含めます。Codex CLIはコピーして手動で貼り付けます。相手で作業フォルダーを選び、Codexを起動して入力欄に貼り付け、確認して送信します。shellのコマンド欄には貼り付けません。
  • 相手のアプリが開かない場合は、依頼文をコピーして手動で渡せます。相手の権限・承認設定は変更しません。

ほかにできること

HTMLをすばやく切り替える

Mogledge（モグリッジ）はknowledge内のHTMLをタブで開き、左右2列でも表示できます。タブの切替・並べ替え・列移動・左メニューの開閉では、入力・Canvas・JavaScriptの実行状態を保ちます。同じHTMLを左右で開くと、それぞれ独立した状態になります。

名前・全文・お気に入りから開く

  • クイックオープン：名前・相対パスで探し、最大20件を表示します。
  • 全文検索：HTML本文を20件ずつ検索し、フォルダー配下に絞れます。
  • お気に入り：HTMLとフォルダーを合わせてroot別に最大50件。検索中も表示します。
  • 最近の文書：時計ボタンで最大50件を表示します。お気に入りのフォルダーを選ぶとツリーのその場所へ移動します。

作業セットを保存

作業セットは最大10組・各30文書で、列・タブ順・選択・倍率を保存します。呼出し時に既存文書の状態を保ち、新しい未選択文書は選ぶまで読み込みません。入力値はセットに含めません。

呼出しキーを割り当てる

管理画面でセットにCtrl/Cmd+Shift+1〜0を割り当てられます。0は10番目です。番号はこのルートの安定したセットIDに保存し、名前・順序が変わっても保持します。未割当は無操作で、削除した番号が別セットへ移ることはありません。アプリ内だけで使い、HTML自身のキー操作・入力・IME・ダイアログを優先します。

履歴・表示倍率

戻る・進むは列ごとに最大32件です。閉じた文書は起動中の直近10件から開き直せます。倍率は文書ごとに50〜200%へ変えられ、アプリの操作部分は拡大しません。

ファイル・フォルダーを整理

ツリーからHTML・フォルダーの作成、名前変更、並べ替え、移動、ごみ箱、パスコピー、OSで開く操作を使えます。HTML本文の編集は外部のAIやエディターで行います。

作成・編集は同期外のローカルフォルダーで。 OneDrive同期外の通常のローカルフォルダーを使ってください。OneDrive同期フォルダー内のファイル・フォルダー操作は失敗する場合があります。

保存済み入力の管理

保存APIに対応したHTMLは入力状態を復元できます。保存済み入力を書き出す・取り込む操作では、ファイルと必要なbackup先を選び、置換と停止・再読み込みを確認します。平文JSONは内容を確認して安全に保管してください。

文書を開く

  1. ルート選択ボタンまたは「設定 → Mogledge 専用フォルダー」から、新しい専用フォルダーを作成するか、既存フォルダーを登録し、一覧から選んで開きます。ガイド・テンプレート・Codex / Claude Skills を配置し、競合する既存ファイルは上書きしません。子フォルダーは通常のツリーで開きます。登録解除後もフォルダー・HTML・保存データは残ります。移動した場合は新しい場所を登録し、管理マーカーで接続し直します。
  2. ツリーのHTMLを選ぶか、クイックオープン・全文検索から開きます。入力や本文検索を使わない間はファイル一覧で閲覧できます。
  3. ツリー・タブの右クリックから左右の列で開けます。タブはドラッグで並べ替え・列移動ができます。

左メニューとタブ

左上のアイコンでメニュー開閉・ファイル・文書検索を切り替えます。境界線をドラッグするか、境界にフォーカスして左右・Home・Endキーで幅を変えます。狭い画面ではメニューが文書に重なります。

作成ボタンの下にお気に入り枠があります。多い場合は枠内をスクロールします。タイトルバーの作業セットアイコンからセットの保存・呼出しを開けます。一番右のヘルプアイコンは、この同じタブを選びます。タブの×・中クリック、またはタブにフォーカスした閉じるキーで閉じます。

左メニュー下部の設定ボタンから「表示言語を選択」を開き、日本語・英語を切り替えます。初回は英語で表示し、保存した言語はすぐに反映されて次回起動後も保持します。版数は下部左側に表示します。

ファイルを作成・移動する

作成・編集は同期外のローカルフォルダーで。 OneDrive同期外の通常のローカルフォルダーを使ってください。OneDrive同期フォルダー内のファイル・フォルダー操作は失敗する場合があります。

作成ボタンはHTML、フォルダー、root直下のフォルダーの順です。フォルダーの作成先・移動先は候補から選び、文字入力で相対パスを絞り込めます。入力文字を任意のパスとして書き込みません。

HTML本文から探す

  • 検索欄右の「検索の詳細設定」でAND／ORとフォルダーを選びます。子孫フォルダーも対象です。詳細の開閉と条件は次回起動にも保持します。
  • 「検索条件をリセット」でAND・ルート全体へ戻します。キーワードと詳細の開閉は変えません。
  • 入力内の×は検索語と結果だけを消します。Escapeはまず検索語を消し、空ならファイル表示へ戻ります。
  • フォルダーの右クリックから「このフォルダー内を検索」も使えます。範囲の×で全体に戻れます。

文書 ID と保存データ

保存データは文書 UUID に対応し、専用フォルダーが変わっても引き継ぎます。正常で重複しない ID は自動で復元します。ID が未設定・不正・重複の場合も HTML は閲覧できますが、保存データは保留します。アプリの通知にある「文書 ID を確認」から、ID の追加、重複データの共有、重複文書への新しい ID の割り当てを明示的に行います。これらの操作は HTML を書き換えます。旧保存データの候補が複数ある場合は、引き継ぐ候補を選んでください。自動選択はしません。フォルダー切り替えや再読み込みの前に、各 HTML の保存操作で入力を保存してください。

更新・保存時の注意

外部で保存すると表示中の文書に反映します。非表示タブは更新待ちになり、表示するまで実行状態を保ちます。「状態をリセットして再読み込み」は入力・Canvas・JavaScriptの実行状態をリセットします。

保存APIは入力状態を保存するためのものです。JavaScriptやCanvas全体の状態は保存しません。リセット・終了前に文書内の保存を完了してください。HTMLの名前変更・移動後は、本文中の相対リンクを外部エディターで確認します。

作成・変更・ごみ箱は通常のローカルフォルダーで使います。ごみ箱への移動に失敗しても永久削除へ切り替えません。復元はOSのごみ箱で行います。

OneDriveでは端末に保持済みの項目を閲覧します。オンラインのみの項目はOS側で端末に保持してから使います。WindowsではWebView2、macOSでは12以降を使います。

主なショートカット

Ctrl+W / Cmd+Wはアプリの操作部やHTMLが処理しないキー操作で使えます。入力欄・IME・ダイアログ・HTML側のキャンセルを優先します。押し続けても1タブだけ閉じ、最後のタブを閉じてもアプリは終了しません。

ヘルプ内の切替

Tabで上の分類に移り、左右の矢印キーまたはSpaceで選べます。その後Tabで表示中の説明に移り、矢印・Page Up・Page Downでスクロールできます。
